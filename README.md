# 摘帽咯 v0.1 网页原型源码说明

更新时间：2026-06-09

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 网页入口，本地直接打开即可查看 |
| `styles.css` | 页面样式 |
| `main.js` | 筛选、单股诊断、报告预览、上传入口等交互逻辑 |
| `data/current_pool.json` | 从 `A股ST股统计_原始快照_2026-06-05.xlsx` 抽取的 253 家股票池数据 |
| `data/current_pool.js` | 让本地 HTML 不依赖服务器也能读取股票池的数据脚本 |

## 当前能力

1. 读取 253 家 ST/*ST 股票池。
2. 展示全池概览和基础筛选。
3. 支持按代码、简称、入池分类、策略标签筛选。
4. 支持 253 家股票的基础单股诊断。
5. 内置 3 家端到端深度样本：`603580.SH`、`600476.SH`、`688496.SH`。
6. 支持报告预览和浏览器打印导出 PDF。

## 当前限制

1. 浏览器端尚未直接解析 `.xlsx`，当前 Excel 数据通过本地脚本预抽取成 JSON。
2. 市场行为窗口数据尚未接入，只录入了部分单日快照和待补字段。
3. 历史相似案例模块目前是结构位，后续需要补历史样本库。
