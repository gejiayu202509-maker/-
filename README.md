# 摘帽咯 v0.3 网页原型源码说明

更新时间：2026-06-12

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 网页入口，本地直接打开即可查看 |
| `upload-format.html` | 上传格式说明页，解释 CSV 需要哪些字段、为什么会进入待复核 |
| `styles.css` | 页面样式 |
| `main.js` | 筛选、单股诊断、报告预览、上传入口等交互逻辑 |
| `data/current_pool.json` | 从 `A股ST股统计_原始快照_2026-06-05.xlsx` 抽取的 253 家股票池数据 |
| `data/current_pool.js` | 让本地 HTML 不依赖服务器也能读取股票池的数据脚本 |
| `data/st_pool_upload_template.csv` | v0.2.1 股票池上传模板 |
| `data/st_pool_upload_example.csv` | 可直接下载测试的 3 行示例股票池 |

## 当前能力

1. 读取 253 家 ST/*ST 股票池。
2. 支持 CSV / JSON 股票池上传，并自动重新识别。
3. CSV 上传会自动寻找包含 `证券代码` 或 `股票代码` 的表头行，允许前面存在标题行或说明行。
4. 自动识别交易所、板块、纯 ST / 纯 *ST / ST+*ST。
5. 上传后先做样本清洗：正常、退市、已摘帽或状态不明样本会排除出当前分析池。
6. 自动输出基础标签层：财务硬指标、审计意见、内控合规、重整、国资/产业方、重大违法、持续经营等。
7. 自动标记原因补齐状态、规则映射状态、公告证据强度和待补/人工复核原因。
8. 按基础观察池、待人工复核池、风险池、高风险排除池、非当前样本进行上传层初步分流。
9. 接入 v0.3 双轨研究卡：Track A 摘帽确定性、Track B 投资窗口。
10. 接入 v0.3 综合分类框架：A+ / A / A- / B / C / D / 非当前。
11. 内置 5 家演示样本：`603580.SH`、`600476.SH`、`688496.SH`、`002217.SZ`、`000656.SZ`。
12. 支持报告预览和浏览器打印导出 PDF。

## 当前限制

1. 浏览器端尚未直接解析 `.xlsx`，Excel 需先按模板另存为 CSV 上传。
2. 上传层自动识别只是基础分拣和样本清洗，不输出最终摘帽概率或投资结论。
3. Track A / Track B 目前是承载框架和样本骨架，不代表完整自动预测模型已经完成。
4. 市场行为窗口数据尚未自动接入，只录入了部分试跑字段和待补字段。
5. 历史相似案例模块目前是结构位，后续需要补历史样本库。
6. 预测策略层还需要继续接入量化因子、历史回放、导师经验和市场行为验证。

## v0.3 与上传模板的关系

网页版本是 v0.3，但上传入口仍沿用 v0.2.1 CSV 模板。

原因是：上传模板只负责“股票池入口”，不要求用户一次性提供公告、行情、历史案例和完整研究结果。v0.3 新增的是网页背后的研究结构，包括数据状态、Track A、Track B、综合分类和报告框架。
