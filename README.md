# 摘帽咯 v0.4 网页原型源码说明

更新时间：2026-06-12

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 网页入口，本地直接打开即可查看 |
| `upload-format.html` | 上传格式说明页，解释 CSV 需要哪些字段、为什么会进入待复核 |
| `styles.css` | 页面样式 |
| `main.js` | 筛选、单股诊断、研究路径、报告预览、上传入口等交互逻辑 |
| `data/current_pool.json` | 从 `A股ST股统计_原始快照_2026-06-05.xlsx` 抽取的 253 家股票池数据 |
| `data/current_pool.js` | 让本地 HTML 不依赖服务器也能读取股票池的数据脚本 |
| `data/st_pool_upload_template.csv` | v0.2.1 股票池上传模板 |
| `data/st_pool_upload_example.csv` | 可直接下载测试的示例股票池 |

## 当前能力

1. 读取 ST/*ST 股票池，并支持 CSV / JSON 上传。
2. 上传后先做样本清洗：正常、退市、已摘帽或历史样本排除出当前分析池。
3. 自动识别交易所、板块、纯 ST / 纯 *ST / ST+*ST。
4. 自动输出基础标签层：财务硬指标、审计意见、内控合规、重整、国资/产业方、重大违法、持续经营等。
5. 显示系统判断总览：A 档重点、B 档修复观察、C 档待复核、D 档风险排除。
6. 显示 v0.4 九步研究路径：样本清洗、风险原因、规则映射、规则缺口、公告证据、财务质量、Track A、Track B、Replay。
7. 单股页展示 v0.4 证据链：规则原因与缺口、公告 reason_id 影响、市场窗口摘要、历史回放参照。
8. Track A 展示摘帽概率与规则修复：当前撤销资格、未来修复线索、主要硬伤、概率抬升节点。
9. Track B 展示交易窗口与市场定价：已反映、拥挤度、是否太晚、后续窗口、主要涨幅阶段。
10. 综合分类支持 A+ / A / A- / B / C / D / 非当前。
11. 内置 5 家演示样本：`603580.SH`、`600476.SH`、`688496.SH`、`002217.SZ`、`000656.SZ`。
12. 支持报告预览和浏览器打印导出 PDF。

## 当前限制

1. 浏览器端尚未稳定解析 `.xlsx`，Excel 建议按模板另存为 CSV 上传。
2. 上传层自动识别只是基础分拣和样本清洗，不输出最终真实概率或投资结论。
3. 规则状态、公告事件、市场窗口和历史回放已经有承载位，但多数当前池股票仍需要外部数据补齐。
4. 市场行为窗口尚未全量自动接入，需要用 iFind、同花顺、Wind、Choice 或后续 Skill 补齐。
5. 历史相似案例目前是 Replay 框架，后续需要补已核验样本库和行情字段。
6. 真实概率需要等历史样本校准后再接入，当前仅输出等级和路径。

## v0.4 与上传模板的关系

网页版本是 v0.4，但上传入口仍沿用 v0.2.1 CSV 模板。

原因是：上传模板只负责“股票池入口”，不要求用户一次性提供公告、行情、历史案例和完整研究结果。v0.4 新增的是网页背后的研究闭环，包括系统判断总览、九步研究路径、规则缺口、公告 reason_id、市场窗口摘要和历史回放参照。
