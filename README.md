# 摘帽咯 v0.2 网页原型源码说明

更新时间：2026-06-11

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 网页入口，本地直接打开即可查看 |
| `styles.css` | 页面样式 |
| `main.js` | 筛选、单股诊断、报告预览、上传入口等交互逻辑 |
| `data/current_pool.json` | 从 `A股ST股统计_原始快照_2026-06-05.xlsx` 抽取的 253 家股票池数据 |
| `data/current_pool.js` | 让本地 HTML 不依赖服务器也能读取股票池的数据脚本 |
| `data/st_pool_upload_template.csv` | v0.2 股票池上传模板 |

## 当前能力

1. 读取 253 家 ST/*ST 股票池。
2. 支持 CSV / JSON 股票池上传，并自动重新识别。
3. 自动识别交易所、板块、纯 ST / 纯 *ST / ST+*ST。
4. 自动输出基础标签层：财务硬指标、审计意见、内控合规、重整、国资/产业方、重大违法、持续经营等。
5. 自动标记原因补齐状态、规则映射状态、公告证据强度和人工复核原因。
6. 按基础观察池、待人工复核池、风险池、高风险排除池进行 v0.2 初步分流。
7. 内置 3 家端到端深度样本：`603580.SH`、`600476.SH`、`688496.SH`。
8. 支持报告预览和浏览器打印导出 PDF。

## 当前限制

1. 浏览器端尚未直接解析 `.xlsx`，Excel 需先按模板另存为 CSV 上传。
2. v0.2 的自动识别只是基础分拣，不输出最终摘帽概率或投资结论。
3. 市场行为窗口数据尚未接入，只录入了部分单日快照和待补字段。
4. 历史相似案例模块目前是结构位，后续需要补历史样本库。
5. 预测策略层还需要继续接入导师经验、历史回放和市场行为验证。
