# 摘帽咯 v0.6 网页原型源码说明

更新时间：2026-06-15

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 网页入口，本地直接打开即可查看 |
| `upload-format.html` | 上传格式说明页，解释 CSV 需要哪些字段、为什么会进入待复核 |
| `styles.css` | 页面样式 |
| `main.js` | 粗筛、候选导出、单股诊断、研究路径、报告预览、上传入口等交互逻辑 |

| `data/st_pool_upload_template.csv` | v0.2.1 股票池上传模板 |
| `data/st_pool_upload_example.csv` | 可直接下载测试的示例股票池 |

## 当前能力

1. 读取 ST/*ST 股票池，并支持 CSV / JSON 上传。
2. 上传后先做样本清洗：正常、退市、已摘帽或历史样本排除出当前分析池。
3. 自动识别交易所、板块、纯 ST / 纯 *ST / ST+*ST。
4. 自动输出基础标签层：财务硬指标、审计意见、内控合规、重整、国资/产业方、重大违法、持续经营等。
5. 显示系统判断总览：粗筛模式 / 精筛模式、补公告候选、暂缓补证、A/B/C/D 分布。
6. 支持下载粗筛候选名单，只导出“补公告候选”，交给 Agent / Skill 定向补公告链和行情窗口。
7. 支持公告链 / 研究结果二次上传，上传后按股票代码合并到单股研究卡，进入精筛展示模式。
8. 显示 v0.6 十一步研究路径：基础池上传、硬风险粗筛、候选导出、公告链回传、规则缺口、软因子、Track A、Track B、复核分叉、预警与建议、Replay。
9. 单股页展示 v0.6 证据链：规则原因与缺口、公告 reason_id 影响、市场窗口摘要、历史回放参照。
10. Track A 展示摘帽概率与规则修复：当前撤销资格、未来修复线索、主要硬伤、概率抬升节点。
11. Track B 展示交易窗口与市场定价：已反映、拥挤度、是否太晚、后续窗口、主要涨幅阶段。
12. 新增综合研究分、Track A 分、Track B 分和复核后可能区间。
13. 新增人工复核分叉：写明复核通过如何升级、不通过如何降级、需要什么证据。
14. 新增软信息因子展示位：国资支持、实控人能力、审计态度、监管压力、重整可信度、行业修复、管理层可信度。
15. 新增粗筛动作列：补公告候选、暂缓补证、直接筛掉、非当前样本。
16. 新增三级预警展示：黄色关注、橙色降级、红色高风险排除，吸收外部交易策略报告的风控口径。
17. 综合分类支持 A+ / A / A- / B / C / D / 非当前。
18. 内置 5 家演示样本：`603580.SH`、`600476.SH`、`688496.SH`、`002217.SZ`、`000656.SZ`。
19. 支持报告预览和浏览器打印导出 PDF。

## 当前限制

1. 浏览器端尚未稳定解析 `.xlsx`，Excel 建议按模板另存为 CSV 上传。
2. 上传层自动识别只是基础分拣、硬风险粗筛和候选导出，不输出最终真实概率或持仓建议。
3. 规则状态、公告事件、市场窗口和历史回放已经有承载位，但多数当前池股票仍需要外部数据补齐。
4. 市场行为窗口尚未全量自动接入，需要用 iFind、同花顺、Wind、Choice 或后续 Skill 补齐。
5. 历史相似案例目前是 Replay 框架，后续需要补已核验样本库和行情字段。
6. 真实概率需要等历史样本校准后再接入，当前综合分数是研究排序分，不是已校准概率。
7. 公告链不是由静态网页实时抓取，需由 Agent / Skill / iFind / 巨潮 / 人工补齐后上传。

## v0.6 与上传模板的关系

网页版本是 v0.6，但基础股票池上传入口仍沿用 v0.2.1 CSV 模板。

原因是：上传模板只负责“股票池入口”，不要求用户一次性提供公告、行情、历史案例和完整研究结果。v0.6 强化的是两段式数据流：先用基础表筛掉明显差样本并导出补公告候选，再由 Agent / Skill 补公告链、规则缺口、行情窗口和软因子，二次上传后进入精筛、评分、预警和报告。
